# Product Inventory & Ordering System

## Overview

A **full-stack web application** developed individually as a project for a **BNCC course**. The application manages product information and supports a basic shopping and ordering workflow.

## Project Information

- **Type:** Course Project · Full-Stack Web Application
- **Course:** BNCC Course
- **Format:** Individual

## Key Features

- User registration and login
- Product and category management
- Admin-only product CRUD operations
- Product stock and price management
- Shopping cart
- Automatic subtotal and total price calculation
- Order creation and order history
- Product image upload

## My Contribution

I developed the project **entirely from the case provided in the course**, including the application structure, backend logic, database relationships, frontend views, authentication, product management, cart, and ordering workflow.

## Tech Stack

- PHP
- Laravel 9
- Blade
- Bootstrap 5
- JavaScript
- Axios
- Laravel Mix

## Main Learning

This project gave me hands-on experience building a full-stack web application with Laravel, including **MVC structure, relational databases, authentication, authorization, CRUD operations, form validation, and transaction workflows**.

A completed individual web application implementing the required product-management and ordering workflow from the course case.
